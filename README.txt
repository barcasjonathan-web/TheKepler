KEPLER - TIENDA ONLINE

1. Abre index.html con doble clic.
2. Para cambiar productos/precios, edita script.js.
3. Para cambiar tu WhatsApp, busca:
   const phone = "34600000000";
   y sustituye ese número por el tuyo con código de país, sin + ni espacios.
4. Sustituye las imágenes de la carpeta img por tus fotos reales cuando las tengas.
5. Para publicar gratis más adelante puedes usar GitHub Pages o Cloudflare Pages.
